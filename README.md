# Muhammad Abubakar - Portfolio Website

Personal portfolio for Muhammad Abubakar, a Full-Stack Developer building responsive, API-driven web applications with React, Python, Node.js, Express.js and modern databases.

## Live site

Deploy this repository on Netlify. Set the production URL in `index.html`, `robots.txt`, and `sitemap.xml` if it changes.

## Highlights

- Responsive layout for desktop, laptop, tablet and mobile
- Project case studies with screenshots, outcomes and technology stacks
- Downloadable resume, WhatsApp, call, email, LinkedIn and GitHub contact paths
- Open Graph social preview card and favicon
- Netlify deployment configuration and security headers

## Run locally

Open `index.html` in a browser, or run a static server:

```powershell
python -m http.server 8080
```

## Deploy to Netlify

1. Sign in to Netlify and select **Add new site** > **Import an existing project**.
2. Choose `abubakar1256/portfolio-website`.
3. Leave build settings empty; `netlify.toml` publishes the project root.
4. Deploy, then set the generated production URL consistently in the SEO files.

## Custom domain

When you purchase a domain such as `muhammadabubakar.dev`, add it in **Netlify > Domain management**. Netlify will provide the DNS records to add at your domain registrar. After it is live, update the URLs in `index.html`, `robots.txt`, and `sitemap.xml`.

## Add project links

The project buttons intentionally use only confirmed destinations. Replace each `Request demo` or `GitHub profile` URL in `index.html` with its exact live-demo or repository link when you make that project public.
